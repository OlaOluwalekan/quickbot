# Saisie vocale et recherche web

## Saisie vocale

Cliquez sur le micro dans le compositeur, parlez, puis cliquez à nouveau pour arrêter. Klecx écrit ce que vous avez dit dans le compositeur, pour que vous puissiez le relire et le modifier avant l'envoi.

- **Durée** : jusqu'à 2 minutes par enregistrement.
- **Limite quotidienne** : un nombre de minutes par jour selon votre forfait : {{plan.FREE.voiceMinutesPerDay}} avec Free, {{plan.LITE.voiceMinutesPerDay}} avec Lite, {{plan.STANDARD.voiceMinutesPerDay}} avec Standard et {{plan.PRO.voiceMinutesPerDay}} avec Pro.
- **Coût** : la transcription utilise quelques crédits de **votre propre** solde, selon la durée de l'enregistrement, même dans l'espace de quelqu'un d'autre.
- **Autorisation du micro** : la première fois, votre navigateur demande l'autorisation. Si vous l'avez refusée, autorisez le micro pour ce site dans les réglages de votre navigateur.

## Recherche web

Klecx cherche sur le web de lui-même quand une question demande des informations récentes ou précises, comme des prix, des actualités ou des nouveautés. Vous n'avez rien à activer.

- **Sources** : les réponses fondées sur une recherche affichent des références numérotées et une liste de sources.
- **Coût** : chaque recherche effectuée par Klecx ajoute {{credits.search}} crédits à la réponse, payés par le propriétaire de l'espace comme le reste de la réponse.
- **Limite quotidienne** : chaque personne peut faire un nombre de recherches par jour dans les espaces d'un même propriétaire, fixé par le forfait de ce propriétaire : {{plan.FREE.searchesPerDay}} avec Free, {{plan.LITE.searchesPerDay}} avec Lite, {{plan.STANDARD.searchesPerDay}} avec Standard et {{plan.PRO.searchesPerDay}} avec Pro. Une fois la limite atteinte, Klecx répond sans chercher et l'indique dans son raisonnement.
- **La désactiver** : désactivez **Rechercher sur le web si utile** dans **Paramètres → Préférences de l'IA**. Klecx répond alors uniquement à partir des connaissances du modèle.
