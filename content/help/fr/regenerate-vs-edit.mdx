# Régénérer vs Modifier

Lorsqu'une réponse d'IA ne convient pas parfaitement ou que vous souhaitez explorer une formulation différente, Klecx propose deux méthodes complémentaires : la **Régénération** et la **Modification en ligne**.

## 1. Régénérer une réponse

Cliquer sur le bouton **Régénérer** au bas d'une carte de réponse déclenche une nouvelle génération complète par le modèle d'IA tout en conservant le prompt d'origine et le contexte.

- **Gestion non destructive des versions** : Klecx ne supprime jamais vos générations antérieures. Lorsque vous régénérez, un indicateur de version s'affiche (par exemple, `2 / 2`).
- **Navigation entre versions** : Utilisez les boutons `Préc` et `Suiv` (ou les flèches du clavier `←` et `→`) pour passer d'une version à l'autre en toute fluidité.
- **Changement de modèle** : Vous pouvez sélectionner un modèle différent (passer de Économique à Standard) lors de la régénération pour comparer les résultats côte à côte.

## 2. Modifier une réponse existante

Parfois, l'IA répond correctement à 95 %, mais un léger ajustement ou un extrait de code personnalisé est nécessaire. Plutôt que de dépenser des crédits pour une régénération complète, cliquez sur **Modifier la réponse**.

- **Éditeur Markdown intégré** : Modifiez le texte directement avec un aperçu en temps réel.
- **Historique d'audit** : Les réponses modifiées affichent un badge « Modifié » pour informer votre équipe des révisions effectuées.
- **Afficher l'original** : Vous pouvez basculer entre vos modifications personnalisées et le texte brut d'origine de l'IA à tout moment.

## 3. Modifier les prompts précédents

Si vous désirez corriger ce que vous avez demandé plus haut dans le fil de discussion, vous pouvez éditer votre prompt initial. Klecx crée alors une nouvelle branche de conversation à partir de ce point, vous permettant d'explorer des pistes alternatives sans perdre la branche précédente.
