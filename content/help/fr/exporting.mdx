# Exporter des espaces de travail

Vos recherches et vos écrits dans Klecx vous appartiennent. Nous mettons à votre disposition plusieurs formats d'exportation propres pour vous permettre d'intégrer vos travaux dans des bases de connaissances, des dépôts de documentation ou des présentations clients.

## Formats d'exportation disponibles

1. **Markdown (`.md`)** :
   - Conserve l'intégralité des titres, listes, blocs de code avec coloration syntaxique, formules mathématiques KaTeX et citations.
   - Idéal pour coller dans Obsidian, Notion, les wikis GitHub ou les générateurs de sites statiques.

2. **Portable Document Format (`.pdf`)** :
   - Génère un document mis en page et prêt à l'impression, comprenant les versions actives des réponses, les tableaux formatés et les diagrammes.
   - Idéal pour les livrables clients officiels et les synthèses exécutives.

3. **Données structurées (`.json`)** :
   - Sérialisation complète des tours de conversation de votre espace, des branches de versions, des horodatages, des paramètres de modèles et des journaux de réflexion.
   - Parfait pour l'archivage par programme, les flux automatisés et les sauvegardes de données personnelles.

## Comment exporter

Cliquez sur le menu **... (Plus d'options)** dans le coin supérieur droit de n'importe quel espace de travail, choisissez **Exporter l'espace de travail**, puis sélectionnez le format souhaité.
