# Exporter

Vous pouvez télécharger des réponses et des documents pour les utiliser ailleurs.

## Formats

1. **Markdown (`.md`)**, avec tous les forfaits. Conserve les titres, listes, tableaux, blocs de code et formules. Fonctionne bien dans les applications de notes et les outils de documentation.
2. **PDF (`.pdf`)**, avec les forfaits payants. Un document mis en forme, prêt à envoyer ou à imprimer.
3. **Word (`.docx`)**, avec les forfaits payants. Un document modifiable.

Dans un espace de travail partagé, télécharger demande le rôle d'Éditeur ou plus, et les formats disponibles dépendent du forfait du **propriétaire de l'espace**. Un format non inclus est grisé, avec une explication.

## Télécharger une réponse

Ouvrez **Exporter** en bas d'une réponse et choisissez un format. Vous obtenez la version que vous consultez : le texte modifié, ou l'original si vous êtes passé à celui-ci.

## Télécharger un document

Ouvrez **Télécharger** sur un document :

- **Fichier d'origine** : le fichier tel qu'il a été importé.
- **Version modifiée** : le texte enregistré, en Markdown, PDF ou Word. Les modifications non enregistrées ne sont pas incluses ; enregistrez d'abord.

Les documents générés (ceux que Klecx rédige pour vous) se téléchargent de la même façon. Voir [Documents de l'espace de travail](/help/documents).

Les téléchargements sont limités à un nombre par jour, qui dépend du forfait.
