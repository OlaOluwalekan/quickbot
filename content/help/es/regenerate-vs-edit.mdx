# Regenerar o editar

Cuando una respuesta no es del todo correcta, puedes pedir a Klecx una nueva versión (**Regenerar**) o corregirla tú mismo (**Editar**). Ninguna de las dos borra nada.

## 1. Regenerar una respuesta

**Regenerar**, al pie de una respuesta, pide una nueva respuesta al mismo mensaje. Usa créditos como un mensaje nuevo.

- **Se conservan todas las versiones**: un contador como `2 / 2` indica qué versión estás leyendo.
- **Cambiar de versión**: usa las flechas junto al contador, o las teclas `←` y `→` cuando el contador tiene el foco.
- La nueva versión se escribe con el modelo **Rápido y Eficiente**.

## 2. Editar una respuesta

Si una respuesta es casi correcta, haz clic en **Editar** y corrígela tú mismo. Editar no usa créditos.

- **Editor y vista previa**: cambia el texto en el editor y comprueba el resultado en la vista previa.
- **Marca de edición**: las respuestas editadas aparecen marcadas, para que los demás sepan que el texto cambió.
- **Ver original**: cambia en cualquier momento entre tu texto editado y la respuesta original, o elige **Restaurar el original**.

Las exportaciones y los enlaces públicos pueden mostrar el texto editado o el original (consulta [Exportar](/help/exporting) y [Compartir](/help/sharing)).

Los mensajes no se pueden editar después de enviarlos. Para preguntar algo de otra forma, envía un mensaje nuevo o crea un espacio de trabajo nuevo a partir de una pregunta al margen.
