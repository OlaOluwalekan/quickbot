# Regenerate vs Edit

When an answer isn't quite right, you can ask Klecx for a new version (**Regenerate**) or correct it yourself (**Edit**). Neither one deletes anything.

## 1. Regenerating an Answer

**Regenerate**, at the bottom of an answer, asks for a new answer to the same prompt. It uses credits like a new message.

- **Every version is kept**: a counter such as `2 / 2` shows which version you are reading.
- **Switching versions**: use the arrows next to the counter, or the `←` and `→` keys when the counter is focused.
- The new version is written with the **Fast & Efficient** model.

## 2. Editing an Answer

If an answer is almost right, click **Edit** and correct it yourself. Editing uses no credits.

- **Editor and preview**: change the text in the editor and check the result in the preview.
- **Edited badge**: edited answers are marked, so others know the text was changed.
- **View original**: switch between your edited text and the original answer at any time, or choose **Revert to original**.

Exports and public links can show either the edited text or the original (see [Exporting](/help/exporting) and [Sharing](/help/sharing)).

Prompts can't be edited after they are sent. To ask something differently, send a new message, or start a new workspace from a side question.
