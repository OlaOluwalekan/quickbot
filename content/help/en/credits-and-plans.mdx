# Credits & Plans

Everything Klecx does with AI uses **credits**: answers, side questions, document reviews, images, web searches and voice transcription. Each model option shows its typical cost before you send.

## How Credits Work

- When you send a message, Klecx sets aside enough credits for the answer. When the answer is finished, only what it really used is taken, and the rest is returned.
- If an answer fails before any text is written, nothing is charged. If you stop an answer, or it fails part-way, only the text already written is charged.
- In a shared workspace, the **workspace owner's** credits pay for everything, except voice input, which uses the speaker's own credits.

## Running Out of Credits

When the balance is too low for an answer, Klecx tells you before sending and nothing is charged. Switch to **Fast & Efficient** to use fewer credits. In someone else's workspace, the message says when the **owner** is out of credits, or when you have reached the monthly limit the owner set for you.
