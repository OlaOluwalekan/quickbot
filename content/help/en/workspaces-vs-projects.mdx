# Workspaces vs Projects

Klecx uses a two-level organizational structure designed to help you stay focused without drowning in infinite sidebar lists: **Workspaces** and **Projects**.

## What is a Workspace?

A **Workspace** is an active conversation thread and thinking canvas. Each workspace has:
- A specific focus or topic.
- A linear progression of prompts and responses with version branches.
- Dedicated context memory that is sent to the AI model during generations.
- Independent privacy and sharing controls.

You can think of a workspace as an open notebook dedicated to solving one task.

## What is a Project?

A **Project** is a collection or container of related Workspaces. For example:
- **Project: Website Redesign 2026** contains workspaces like *Copywriting*, *Brand Palette Discussion*, and *SEO Strategy*.
- **Project: Python Backend** contains *API Architecture*, *Database Schema*, and *Performance Tuning*.

## When to Create a New Project

Create a Project when:
1. You are starting a long-term goal that requires multiple independent conversations.
2. You want to share an entire cluster of workspaces with a specific team or client.
3. You want to keep your sidebar tidy by collapsing completed work.

Workspaces can also live in your **Default Workspaces** root without belonging to any project, giving you the flexibility to take quick scratch notes whenever inspiration strikes.
