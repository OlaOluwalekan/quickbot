# Exporting

You can download answers and documents to use them elsewhere.

## Formats

1. **Markdown (`.md`)**, on every plan. Keeps headings, lists, tables, code blocks and formulas. Works well in note-taking apps and documentation tools.
2. **PDF (`.pdf`)**, on paid plans. A formatted document, ready to send or print.
3. **Word (`.docx`)**, on paid plans. An editable document.

In a shared workspace, downloading needs the Editor role or above, and the formats you can use follow the **workspace owner's** plan. A format that isn't included is greyed out with an explanation.

## Downloading an Answer

Open **Export** at the bottom of an answer and choose a format. You get the version you are currently viewing: the edited text, or the original if you switched to it.

## Downloading a Document

Open **Download** on a document:

- **Original file**: the file exactly as it was uploaded.
- **Edited version**: the saved text, as Markdown, PDF or Word. Unsaved changes are not included; save first.

Generated documents (documents Klecx writes for you) download the same way. See [Workspace documents](/help/documents).

Downloads are limited to a number per day, which depends on the plan.
